## ✨ Overview

Auto Save automatically saves your file while you type — intelligently and efficiently.

It detects real changes, waits for idle time, and saves in the background without interrupting your workflow.

Built for developers who want peace of mind while coding.

---

## 🚀 Features

- ⚡ Smart idle-based saving
- ⏱ Custom save delay (ms)
- 🔁 Force save interval (backup safety timer)
- 🔄 Undo / Redo aware
- 🔔 Optional minimal top notification
- 🧩 Lightweight & optimized
- 📴 Works offline
- 🎨 Clean modern UI

---


## 📦 Installation

### Install from Acode Plugin Store (Recommended)

1. Open **Acode**
2. Go to **Settings → Plugins**
3. Tap **Explore**
4. Search for **Auto Save**
5. Tap **Install**

## 🎛 Configuration

Accessible via sidebar panel.

You can configure:

- Enable / Disable Auto Save
- Delay (ms)
- Force Save Interval (ms)
- Notification toggle

---

## 🧠 How It Works

1. Detect file content change  
2. Wait until typing stops (idle delay)  
3. Save automatically  
4. Show subtle feedback (optional)  

It prevents unnecessary duplicate saves and properly handles undo/redo changes.
